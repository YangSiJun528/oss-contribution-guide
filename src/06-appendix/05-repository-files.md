# 저장소에서 확인할 파일

일반적으로 저장소에서 찾아볼 수 있는 파일과 그 의미를 저장해보았습니다.

파일 이름과 위치는 프로젝트마다 다릅니다. 혹은 문서가 저장소가 아닌 별도 위치에 있을 수 있습니다.

| 대표적인 파일 이름 | 역할 |
| --- | --- |
| `README.md`, `docs/`, 프로젝트 웹사이트 | 프로젝트의 목적, 사용법, 상태와 다른 문서의 위치 |
| `LICENSE`, `COPYING` | 코드를 사용·수정·배포할 수 있는 조건 |
| `NOTICE`, `COPYRIGHT` | 저작권·라이선스 고지와 외부 구성요소 정보 |
| `CONTRIBUTING.md` | 개발 환경, 테스트, 커밋, Issue와 PR 제출 방법 |
| `DEVELOPMENT.md`, `HACKING.md` | 빌드·실행·디버깅 등 개발 방법 |
| `CODE_OF_CONDUCT.md` | 기대하는 행동, 금지되는 행동과 신고 방법 |
| `SECURITY.md` | 보안 취약점을 비공개로 신고하는 방법 |
| `GOVERNANCE.md` | 프로젝트의 의사결정 구조와 절차 |
| `MAINTAINERS`, `OWNERS`, `.github/CODEOWNERS` | 담당자와 검토·승인 권한 |
| `SUPPORT.md` | 질문과 사용자 지원을 요청할 위치 |
| `CHANGELOG.md`, 릴리스 노트 | 버전별 변경 사항 |
| `ROADMAP.md` | 계획된 작업과 프로젝트의 방향 |
| CLA, DCO 또는 sign-off 안내 | 기여자가 동의하거나 확인해야 할 법적 조건 |
| `AI_POLICY.md`, `LLM_POLICY.md` 등 | AI 사용 범위와 공개 방법. 정해진 표준 파일명은 없음 |
