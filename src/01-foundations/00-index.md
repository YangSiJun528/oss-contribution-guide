# 1부. OSS 기여의 판단 기반

OSS 기여는 공개된 코드를 고쳐 제출하는 일만을 뜻하지 않습니다. 라이선스는 코드를 사용할 권리를, 거버넌스와 운영 관행은 참여할 방법을, 공동체의 상황은 기여자가 지켜야 할 책임의 범위를 각각 정합니다.

이 부에서는 기여 전에 필요한 최소한의 판단 기반만 다룹니다. OSS의 전체 역사, 라이선스의 법률적 세부 해석, 거버넌스 이론과 개별 AI 정책의 전문은 연결된 공식 자료에서 확인합니다.

다음 장들은 순서대로 다음 질문에 답합니다.

1. 기여를 시작할 이유와 감수할 비용이 분명한가?
2. 공개된 코드를 어떤 권리와 조건에서 다룰 수 있는가?
3. 프로젝트는 누가 어떤 방식으로 운영하는가?
4. 제출한 변경은 다른 참여자에게 어떤 비용을 만드는가?
5. 그런 비용을 줄이기 위해 기여자는 어떻게 행동해야 하는가?
