# OSS 개요

이 절에서는 OSS 생태계를 이해하는 데 필요한 기본 배경을 간단히 설명합니다. OSS와 FOSS의 의미, 라이선스, 프로젝트를 구성하는 사람과 조직, 프로젝트마다 다른 운영 방식과 문화를 다룹니다.

각 주제는 이미 좋은 자료가 많기 때문에 이 가이드에서는 기여를 시작하기 전에 알아야 할 정도로만 요약합니다. 더 구체적인 정의와 절차가 필요하면 각 글의 **더 보기**에 연결된 자료와 대상 프로젝트의 공식 문서를 확인해야 합니다.

AI가 코드 작성과 기여 환경을 바꾼 점, 프로젝트별 AI 정책, 오픈웨이트와 오픈소스 AI의 구분은 여기서 다루지 않습니다. 관련 내용은 [AI와 OSS 기여](../05-ai-and-oss/00-index.md)와 [OSS와 AI 사례 노트](../07-appendix/02-oss-ai-case-notes.md)를 참고합니다.
