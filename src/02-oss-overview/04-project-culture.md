# 프로젝트의 방식과 문화

## 관리하고 소통하는 방식

- GitHub·GitLab 등의 코드 호스팅
- Issue·Jira 등의 작업 관리
- PR·MR·Gerrit·이메일 패치 등의 기여 방식
- 메일링 리스트·포럼·Discord·Slack 등의 소통 채널
- 비공식 대화와 공식 의사결정 기록의 차이
- 이 가이드의 실제 절차는 GitHub를 기준으로 설명

## 실제 문화 확인하기

- 응답 속도와 리뷰 방식
- 친절하거나 불친절할 수 있음
- 문서에 적힌 규칙과 암묵적인 규칙
- AI 사용에 대한 입장
- 최근 Issue와 PR에서 실제 분위기를 확인하는 방법
