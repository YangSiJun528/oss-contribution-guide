# PR 제출 이후

## 제출한 PR의 결과 받아들이기

- 병합
- 수정 요청
- 다른 변경으로 이미 해결됨
- 프로젝트 방향과 맞지 않아 거절됨
- 장기간 응답이 없음
- 병합과 릴리스는 별개라는 점
- 병합되지 않아도 검토 가능한 PR을 제출했다면 가이드의 목표는 달성한 것

프로젝트마다 검토 속도가 다르므로 답변을 기다리는 시간을 일률적으로 정하기는 어렵습니다. 충분히 기다린 뒤에도 진행 상황을 알 수 없다면 PR의 공개된 대화에서 간결하게 질문합니다. 반복해서 멘션하거나 여러 채널로 같은 요청을 보내는 것은 피합니다.

### 팁

관리자가 다른 일로 바쁠 수 있음. 본인 제출 외에도 전체적으로 리뷰가 미뤄지고 있는 경우 요청하지 않고 조금 더 기다려봅시다.

기다리지 말고, 다른 작업을 찾는 것도 좋습니다. 경우에 따라 수 주에서 수 개월까지 걸릴수도 있습니다.

## 다음 참여 방식 선택하기

가이드에 따라서 프로젝트에 참여한 이후라면 정확하게 알지는 못해도 다음과 같은 부분을 알게 될 것입니다.

기여하는 flow, 작업을 테스트하고 검증하는 법, 프로젝트가 무엇이며 어떤 식으로 동작하는지.

그럼 이제 이 지식을 바탕으로 새로운 이슈를 찾아 빠르게 해결하거나, 건의하거나, 사이드 프로젝트에 도입해보거나, 아니면 새로운 기여자의 활동 or 버그를 찾고 해결하는 것에 도움을 줄 수 있습니다.

- 같은 프로젝트에서 작은 기여 이어가기
- 테스트·리뷰·Issue 재현·트리아지 참여
- 더 큰 작업 제안하기
- 다른 프로젝트 탐색하기
