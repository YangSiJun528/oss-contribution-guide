# 이 가이드의 대상과 목표

## 추천 독자

- OSS 코드 기여가 처음이거나 경험이 많지 않은 사람
- 실제 코드 동작에 영향을 주는 첫 기여를 시도하려는 사람

## 필요한 사전 지식

- 하나 이상의 프로그래밍 언어로, AI 없이도 문서나 검색해서 찾은 자료를 참고해 기본적인 기능을 구현할 수 있음
- 자신이 작성하거나 AI가 생성한 코드의 동작을 이해하고 설명할 수 있음
- Git과 GitHub에 능숙할 필요는 없지만 커밋, 브랜치, Issue, PR의 개념과 기본적인 사용 방법을 알고 있음

## 이 가이드의 범위와 목표

- 문서 작업이 아니라 실제 코드 동작에 영향을 주는 변경을 대상으로 함
- 코드 기여의 세부 경계는 프로젝트 맥락에 따라 판단
- 구체적인 과정은 GitHub 기반으로 설명
- 목표는 병합이 아니라 `검토 가능한 PR 제출`
- 프로젝트의 규칙이 이 가이드보다 우선함
