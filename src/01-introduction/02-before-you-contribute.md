# 기여를 시작하기 전에

- 기여 동기에 정답은 없음
- 사용 중인 프로젝트의 문제, 호기심, 학습, 취미 등에서 시작할 수 있음
- 병합·취업·금전·평판 같은 결과는 보장되지 않음
- 예상보다 많은 시간과 대화가 필요할 수 있음
- 자신이 이해하고 검증한 변경을 제안하는 것을 목표로 함

## 더 보기

- [오픈소스에 기여하는 방법](https://opensource.guide/ko/how-to-contribute/): 일반적인 기여 동기와 참여 흐름을 더 폭넓게 다룸
- [오픈 소스로 미래를 연마하라](https://www.yes24.com/product/goods/80093196): 기여 생태계와 참여 과정을 더 깊게 다루는 책. 2019년 출간이라 AI로 인한 변화는 별도 자료 참고
