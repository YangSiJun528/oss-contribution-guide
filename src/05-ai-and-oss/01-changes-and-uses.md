# AI가 바꾼 OSS 기여

## AI가 바꾼 것

- 코드와 Issue·PR 작성 비용 감소
- 문제를 이해하지 않아도 그럴듯한 결과를 만들 수 있게 된 점
- 코드 생산량이 늘어도 검토 비용은 줄지 않을 수 있음
- 메인테이너가 AI 사용보다 검증되지 않은 결과를 문제 삼을 수 있음

## 문제가 되는 AI 기여

- 재현하지 않은 버그
- 실제 문제와 무관한 Issue
- 검증되지 않은 취약점 보고
- 대량 생성한 Issue와 PR
- 실행하지 않은 테스트 결과
- 존재하지 않는 API나 동작에 대한 설명
- 자동 생성한 리뷰 답변

## 생산적인 AI 활용

- 코드 탐색과 이해 보조
- 구현 후보 비교
- 테스트 초안 생성 후 직접 검증
- 반복 작업 보조
- 충분히 이해하고 검증한 포팅
- 사람이 방향과 최종 책임을 맡는 실험적 프로젝트
