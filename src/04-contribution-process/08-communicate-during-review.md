# 리뷰에서 대화하기

- 리뷰 요청을 정확히 이해하기
- 모호하면 이해한 내용을 되물어 확인
- 동의하지 않으면 근거와 대안 제시
- 수정 후 무엇을 바꿨는지 설명
- 반복 멘션이나 여러 채널을 통한 독촉 피하기
- AI가 생성한 답변을 검토 없이 사용하지 않기
- 병합·수정 요청·거절·무응답을 모두 가능한 결과로 보기
