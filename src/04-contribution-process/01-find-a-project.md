# 기여할 프로젝트 찾기

- 직접 사용하는 프로젝트
- 관심 있거나 공부하려는 프로젝트
- 사용하는 언어와 빌드 환경을 감당할 수 있는지 확인
- 최근에도 관리되는 프로젝트인지 확인
- 외부 기여자의 PR이 실제로 받아들여지는지 확인
- 처음부터 하나로 정하지 않고 후보를 몇 개 비교
