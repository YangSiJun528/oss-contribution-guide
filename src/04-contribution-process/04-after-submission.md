# PR 제출 이후

## PR 결과의 수용

- 병합
- 추가 수정 요청
- 다른 변경으로 이미 해결됨
- 프로젝트 방향과 맞지 않아 거절됨
- 장기간 응답이 없음
- 병합과 릴리스는 별개라는 점
- 병합되지 않아도 검토 가능한 PR을 제출했다면 가이드의 목표는 달성한 것

프로젝트마다 검토 속도가 다르므로 답변을 기다리는 시간을 일률적으로 정하기는 어렵습니다. 충분히 기다린 뒤에도 진행 상황을 알 수 없다면 PR의 공개된 대화에서 간결하게 질문합니다. 반복해서 멘션하거나 여러 채널로 같은 요청을 보내는 것은 피합니다.

### 응답 대기

관리자가 다른 일로 바쁠 수 있습니다. 본인이 제출한 PR 외에도 전체적으로 리뷰가 미뤄지고 있다면 요청하지 않고 조금 더 기다립니다.

응답을 기다리는 동안 다른 작업을 찾는 것도 좋습니다. 검토에는 수 주에서 수 개월이 걸릴 수도 있습니다.

## 기여 경험의 정리

기여를 완료했다면 경험을 기록하여 학습에 활용하거나 외부에 공개할 수 있습니다.

- 해결하려던 문제
- 직접 수행한 변경
- 받은 피드백
- 배운 내용
- 실제 역할과 기여 수준을 과장하지 않기
- 처음 세운 목표 다시 평가하기

## 다음 참여 방식의 선택

이 과정에서 프로젝트의 기여 흐름, 변경을 테스트·검증하는 방법과 프로젝트의 운영 방식을 경험하게 됩니다. 이 지식을 바탕으로 다음 참여 방식을 선택할 수 있습니다.

- 같은 프로젝트에서 작은 기여 이어가기
- 테스트·리뷰·Issue 재현·트리아지 참여
- 더 큰 작업 제안하기
- 다른 프로젝트 탐색하기
