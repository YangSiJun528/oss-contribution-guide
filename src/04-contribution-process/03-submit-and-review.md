# PR 제출하고 리뷰받기

## 커밋과 PR 작성하기

- 프로젝트의 커밋 규칙 확인
- 커밋 메시지와 단위 정리
- CLA·DCO 확인
- 커밋 이메일 노출 확인
- 문제·필요성·해결 방법·검증 결과·한계 작성
- 관련 Issue 연결
- 필요한 경우 Draft PR 사용
- 검토 가능한 상태가 되면 Ready for review로 제출
- 단순 PR 생성과 검토 가능한 PR 제출을 구분

### 더 보기

- [Pull Request 소개][github-pull-request-overview]: PR과 Draft PR 등 GitHub 기능과 기본 흐름

## 리뷰에서 대화하기

- 리뷰 요청을 정확히 이해하기
- 모호하면 이해한 내용을 되물어 확인
- 동의하지 않으면 근거와 대안 제시
- 수정 후 무엇을 바꿨는지 설명
- 반복 멘션이나 여러 채널을 통한 독촉 피하기
- AI가 생성한 답변을 검토 없이 사용하지 않기
- 병합·수정 요청·거절·무응답을 모두 가능한 결과로 보기

### 더 보기

- [Pull Request 리뷰 소개][github-pull-request-reviews]: 승인, 변경 요청, 댓글 등 GitHub의 리뷰 기능
