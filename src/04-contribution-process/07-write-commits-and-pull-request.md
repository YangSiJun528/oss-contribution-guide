# 커밋과 PR 작성하기

- 프로젝트의 커밋 규칙 확인
- 커밋 메시지와 단위 정리
- CLA·DCO 확인
- 커밋 이메일 노출 확인
- 문제·필요성·해결 방법·검증 결과·한계 작성
- 관련 Issue 연결
- 필요한 경우 Draft PR 사용
- 검토 가능한 상태가 되면 Ready for review로 제출
- 단순 PR 생성과 검토 가능한 PR 제출을 구분
