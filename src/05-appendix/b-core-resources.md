# 핵심 참고자료

본문의 정의와 판단 근거를 더 깊게 확인할 자료입니다. 개별 프로젝트의 정책과 특정 기능의 사용법은 각 장에서 해당 공식 문서로 연결합니다.

## 공식 기준

- [Open Source Definition][osi-open-source-definition]: 어떤 배포 조건을 오픈소스라고 부를 수 있는지 정리한 OSI의 기준
- [자유 소프트웨어의 정의][fsf-free-software-definition-ko]: FOSS에서 말하는 사용자의 자유를 설명하는 FSF의 공식 문서
- [OSI 승인 라이선스 목록][osi-approved-licenses]: 특정 라이선스가 OSI의 승인을 받은 오픈소스 라이선스인지 확인하는 목록

## 기여 입문 자료

- [오픈소스에 기여하는 방법][open-source-guide]: 프로젝트 선택부터 기여 이후까지 폭넓게 설명하는 입문 자료
- [네이버 오픈소스 가이드][naver-open-source-guide]: OSS 개념, 라이선스, 거버넌스와 기여 절차를 한국어로 정리한 자료. 오래된 화면과 절차는 최신 공식 문서와 함께 확인할 필요가 있음
- [오픈소스 입문을 위한 아주 구체적인 가이드][parksb-open-source-guide]: Git과 GitHub를 이용한 기여 과정을 구체적으로 보여 주는 한국어 자료. 2018년 글이므로 브랜치 이름과 일부 명령은 최신 공식 문서로 재확인할 필요가 있음

## 프로젝트 운영 자료

- [Producing Open Source Software][producing-open-source-software]: 프로젝트 운영, 커뮤니케이션과 거버넌스를 깊게 다루는 무료 영문 도서
- 『오픈 소스로 미래를 연마하라』(VM 브라수어): 기여 준비부터 커뮤니티 참여까지 체계적으로 설명하는 2019년 도서
- [Nobody's job, everybody's problem: F/OSS in the age of AI][hongminhee-foss-ai-talk]: FOSS의 철학과 유지보수 문제를 AI 시대의 기여 환경까지 연결한 강의 자료
